## 1. Synthetic Data Disclaimer & Purpose

> [!IMPORTANT]
> All organization names, material descriptions, item codes, prices, and engineering specifications contained in the sample datasets and seeding scripts are **fictional/synthetic demonstration data** created specifically for SIH 2026 technical evaluation. They do **NOT** represent real, proprietary internal CPSE databases or official government records.

The purpose of this seed dataset is to enable end-to-end demonstration of the core multi-CPSE deduplication problem, cross-walk mapping, standards equivalence governance, and the complete CPSE $\rightarrow$ CNMC harmonization lifecycle.

### AI & CNMC Prototype Disclaimers:
- **Synthetic Demonstration Match Data:** All similarity scores (composite, lexical, vector, attribute) in the seeded match tables are **manually seeded demonstration values** used to validate database schema, entity relationships, and future workflow visualization. These values were **NOT** generated by a live AI model, sentence transformer, or embedding pipeline.
- **MVP Prototype CNMC Reference Format:** The CNMC codes (e.g., `IN-IND-MECH-BLT-00492`) represent an **MVP Prototype Reference Format** designed for the SIH 2026 demonstration. They do **NOT** represent officially ratified Government of India national codes or official national policy codification.
- **Application-Level Demonstration Approval:** Governance review records and approvals in seed data represent **application-level demonstration approvals** within the prototype workflow, and do not represent approval by any actual national committee or government body.

## 2. Seed Data Execution Instructions

### A. Local Python Execution
To seed the database from your local development environment:

```bash
# Ensure you are at the repository root
cd c:\Users\User\Desktop\CSPES

# Run the seed script using the backend virtual environment
backend\.venv\Scripts\python backend/scripts/seed_demo_data.py
```

### B. Docker Compose Environment
When running inside Docker containers:

```bash
# Execute seeding inside the backend container
docker compose exec backend python scripts/seed_demo_data.py
```

- **Repeatability Status:** Designed and unit-tested for repeatable/idempotent seed behavior. Live PostgreSQL execution and repeated-run verification remain pending.
- **Resetting the Database Baseline:**
